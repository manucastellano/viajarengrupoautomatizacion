# Ventas: seguimiento de consultas

- `planilla-consultas.csv`: se abre con Excel o se importa en Google Sheets (Archivo > Importar). Una fila por consulta.
- `primera-respuesta-whatsapp.md`: mensajes para contestar en el momento.

Valores sugeridos:
- **De dónde llegó:** Instagram, LinkedIn, Web, Recomendación, Vendedor asociado, Publicidad, Pasajera anterior, Otro.
- **Estado:** Nueva, Esperando respuesta, Interesada, Señó, Pagó, No compra.

Cada lunes: contar consultas de la semana, cuántas siguen abiertas y cuántas compraron.
